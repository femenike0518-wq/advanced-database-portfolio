# MIT 8103 Advanced Database Systems Portfolio

## Case Study: SwiftBank

SwiftBank is a fictional banking system used for this individual practical database portfolio. The system manages customers, bank accounts, balances and transactions.

## Portfolio Activities

- **Portfolio 1:** Database Design and Modelling — relational schema, tables, keys and relationships.
- **Portfolio 2:** Query Processing and Optimisation — SQL queries, execution plans and indexing.
- **Portfolio 3:** Transactions and Concurrency — commit, rollback and transaction isolation.
- **Portfolio 4:** NoSQL and Advanced Data Models — MongoDB documents, embedded account details and queries.
- **Portfolio 5:** Distributed and Cloud Database Exercise — planned work on distributed database concepts.

## Tools

- PostgreSQL and pgAdmin
- MongoDB Community Server and MongoDB Compass
- Git and GitHub
